联通 IBOS 批量查询助手 — 使用说明
====================================

一、这是什么
------------
纯“外部操作”式网页自动化工具:
- 不在页面注入任何脚本、不改写任何接口,因此不会触发 IBOS 风控(API 劫持/前端注入检测均不涉及);
- 通过 macOS 系统层面模拟真实鼠标点击与键盘输入,操作你已登录的 Edge 浏览器;
- 每个姓名:输入 → 查询 → 用浏览器「另存为」保存查询结果页,然后直接查下一个;
  保存后弹出的下载提示条,会在下一次点击(如点姓名输入框)时自动关闭,无需单独处理;
  如需详情页,把 config.json 中 enable_detail 改为 true 即可(会再点「详情」并保存第 2 个页面);
- 提供置顶悬浮窗,控制启停、查看实时日志、标定坐标。

二、首次使用三步走
------------------
1) 授权(必须)
   系统设置 → 隐私与安全性 → 辅助功能:勾选「终端」(双击 .command 启动用的应用);
   系统设置 → 隐私与安全性 → 屏幕录制:同样勾选「终端」。
   授权后需重新启动工具(完全退出终端里运行的进程)。

2) 打开 Edge 并登录 IBOS
   用 Edge 登录 ibos.10010.com,进入“查询”页面,让该标签页保持在前台;
   把 Edge 窗口拖到【主显示器】,位置/大小保持不动(坐标按窗口位置标定)。

3) 启动并标定
   双击「启动查询工具.command」→ 悬浮窗出现 → 点「标定坐标」;
   按全屏提示依次点击:姓名输入框 → 订单号输入框(可选) → 查询按钮;
   ②订单号输入框仅「按订单号查询」时用到,Enter 可跳过(未标定时自动按姓名框上方推算);
   ④⑤⑥ 均为可选(④详情按钮、⑤返回按钮、⑥结果区域),按 Enter 跳过。
   完成后坐标自动存入 config.json,并生成标定参考截图。

三、运行
--------
1) 在悬浮窗状态卡右侧选择「查询方式」:按姓名 / 按订单号 / 按订购号码;
   在查询列表输入框中粘贴查询内容(每行一条,# 开头为注释);
   按姓名时每行一个姓名,按订单号时每行一个订单号(16 位纯数字,如 1234567890123456),
   按订购号码时每行一个 11 位手机号;
   也可点「从文件…」选择你的 txt 文件。
2) 点「开始查询」。运行期间:
   - 请勿移动鼠标/切换窗口,保持 Edge 在前台;
   - 悬浮窗自动最小化,屏幕左上角出现迷你控制条(可拖动),可随时「停止」。
3) 默认每个单子保存一个网页:
   导出结果/<姓名 或 订单号>__查询结果.mhtml(或 .html + _files 文件夹)
   (若开启 enable_detail,还会保存:导出结果/<姓名 或 订单号>__详情.mhtml)
4) 中断后可再次点「开始」,会询问是否从上次进度继续(会显示上次完成到哪一位)。
5) 查询跑完,软件会【自动】解析所有查询结果网页并生成:
   - 「导出结果/查询结果汇总.xlsx」:每个订单一行,30+ 字段(订单ID/号码/状态/费用/联系人/配送/产品/短信等),
     并附带「查询报告」工作表(总览、各姓名明细、订单状态分布);
   - 「导出结果/查询报告_时间戳.txt」:纯文本查询报告,方便快速查看/转发。
   (解析本地已保存的网页,纯离线处理,不触碰平台;也可随时点「导出 Excel」手动重新生成)

【解析准确性说明】
- 导出列集(用户指定表头):
  日期 / 姓名 / 开卡人 / 团队长 / 归属地 / 学校 / 手机号 / 联系电话 /
  订单编号 / 订单状态是否通过审核 / 运单号 / 短链 / 用户办理方式 / 是否新生 / 套餐 /
  发出日期 / 激活日期 / 宽带。
- 按订单号查询时,最前面额外保留一列「查询订单号」(标识列,方便对照名单与定位空行);
  按姓名查询时无此列,「姓名」列=订单中的联系人。
- 能自动填写的列:日期←成交时间(月.日)、姓名←联系人、手机号←号码(纯11位)、
  联系电话←联系人电话、订单编号←订单ID、订单状态是否通过审核←订单状态、
  运单号←物流单号、短链←短链详情中提取的 http(s) 链接(去重)、套餐←产品信息;
  其余列(开卡人/团队长/归属地/学校/用户办理方式/是否新生/发出日期/激活日期/宽带等)
  因订单数据中不含,保持留空,可自行补录。
- 按订单号查询时,Excel 行序 = 名单.txt 中订单号的顺序(与你的名单一一对应);
  某个订单号查不到结果(文件无订单/缺失)时,该行会保留、仅「查询订单号」列有值,其余字段留空,
  方便你对照名单找出哪些单没查到;名单中重复的订单号会同样输出多行。
- 性能:解析采用多线程并行,大批量(数百文件)导出显著提速;单个文件损坏/异常自动跳过,不影响整体。
6) 速度说明(已按"策略不触发风控"多次提速):
   - 操作随机停顿 0.35-0.8s → 0.25-0.55s;鼠标移动/点击/输入等各处停顿同步收紧;
     输入框 ⌘A 全选后直接粘贴覆盖,省去多余 backspace;
   - 查询结果加载等待 2.5-4.0s → 1.2-1.8s(多次缩短;有「保存后内容验证」兜底:
     若等太短导致保存了旧页面/未加载完,日志会警告"未找到查询值",届时把 result_wait_s 调大即可);
   - Edge 已在前台时自动跳过"激活应用"步骤(省 0.2-0.5s/单);
   - 【保存目录懒修正】:利用 Edge 记住上次保存目录——首次保存 ⌘⇧G 设置目录后,
     后续保存面板自动停在导出目录,直接输入文件名保存,省去每次跳转(省 1.5-2s/单);
     万一目录跑偏(文件存到别处),自动 ⌘⇧G 修正后重存,无需人工干预;
   - 唯一无法加速的是网页写入(浏览器保存 MHTML 大页面需 20s+,属硬耗时)。
   💡 提速建议:到 系统设置 → 隐私与安全性 → 屏幕录制 开启权限后,在「标定坐标」里把⑤结果区域也标上,
   wait_mode=auto 会自动改为「结果一出即继续」的画面检测(替代固定 1.2-1.8s 等待),平均每单再省 1 秒。
   速度参数都在 config.json(action_delay_s / result_wait_s),想再保守随时可调大。

【稳定性 / 容错 / 智能特性】
- 窗口位移自动补偿:标定完成后,若 Edge 窗口被意外移动(哪怕不小心挪了一点),
  工具会自动检测位移并平移全部坐标,无需重新标定;日志与「检查环境」都会提示。
- 失败自动重试:单个姓名保存未确认时,自动完整重查一次(重新输入→查询→保存);
  若文件其实已保存成功,会自动识别并跳过重试,绝不重复保存;
  文件被存到别处时会自动 ⌘⇧G 修正目录重存(自愈),修正后仍失败才报错停止。
- 保存面板等就绪:⌘S 后等系统保存面板真正弹出(连续 2 次采样确认)才输入文件名,
  绝不往页面盲发按键;每次保存前还会自动清理可能遗留的旧面板。
- 【保存后内容验证】:保存完成会检查文件——文件过小(可能保存失败),或内容里
  找不到本次查询值(可能是查询无结果、或查询没生效保存了旧页面),日志会给出警告,方便及早发现。
- 【Edge 存活检查】:Edge 崩溃或被关闭时,会立即明确停止并提示,不会继续对桌面盲点;
  开始前也会预检 Edge 是否在运行、导出目录是否可写。
- 【坐标合理性检查】:开始前检查标定坐标是否超出屏幕范围(如换了显示器/分辨率),
  超屏会在日志提示建议重新标定。
- 【名单防呆】:按订单号查询时,若名单里有非数字行,开始前会提示检查。
- 智能等待结果:wait_mode=auto(默认)下,若已开启屏幕录制权限并标定⑤结果区域,
  自动改为「检测页面画面变化」等结果(结果一出现立刻继续,更快);否则用固定等待。
- 错误原因细分:保存失败时日志会区分「面板未弹出 / 文件未写入 / 存到别处」,
  并给出针对性处理建议。
- 运行日志超过 5MB 自动轮转归档(运行日志.log.old),不会无限膨胀。
- Excel 被占用时:若 查询结果汇总.xlsx 正被 Excel/WPS 打开,自动等待重试并给出明确提示。

四、重要配置(config.json,一般无需手改)
--------------------------------------
- enable_detail:
    false = 只保存查询结果页(当前默认);
    true  = 点击详情并保存第 2 个页面(需先标定③详情按钮,并确认 detail_mode 与页面一致)。
- detail_mode(仅在 enable_detail=true 时生效):
    new_tab    = 详情在新标签页打开(点详情后 ⌘W 关闭详情标签)
    same_page  = 详情在当前页跳转(配合 back_button 或 ⌘[ 返回)
    dialog     = 详情是弹窗(按 Esc 关闭)
- save_folder_method:
    goto_folder= 每次保存自动 ⌘⇧G 跳转到「导出结果」目录(默认,推荐,可靠);
    remember   = 用浏览器记住的保存目录(需先手动对任意页面「另存为」,把位置选到「导出结果」)。
- save_dialog_delay_s: 等待系统保存面板弹出的最长时间;已自动等待面板就绪后再输入,一般无需改动。
- save_screenshots: true 时每个姓名额外保存一张屏幕截图(需屏幕录制权限)。
- wait_mode: auto=智能(默认,有屏幕录制权限+已标定结果区域时自动用画面变化检测,否则固定等待);
    fixed=固定等待;screen_change=强制画面变化检测(需标定⑤并开屏幕录制)。
- auto_retry: 单个姓名失败后的自动重试次数(默认 1=自动重查一次;0=不重试)。
- reload_before_each: same_page 模式下建议 true(每名查询前刷新页面)。
- auto_export_excel: true 时查询结束自动解析并生成 Excel(默认开启);false 只手动点「导出 Excel」。
- stop_on_error: true 时单条失败(重试后仍失败)即停止,便于人工处理。
- log_max_mb: 运行日志超过该大小(MB)自动轮转归档(默认 5)。

五、常见问题
------------
Q: 点击没反应/输入无效?
A: 辅助功能权限未开启或未重启工具。点「检查环境」查看。
Q: 为什么之前会保存两次?
A: 旧版本保存对话框未就绪时就开始输入,导致保存失败后自动重试,弹了两次保存框。新版本会等保存面板真正弹出后再输入,且失败不再盲目重试,每个姓名只保存一次。
Q: 保存到别的位置?
A: 默认已自动跳转「导出结果」目录。若日志提示"文件被保存到其他位置",把 save_folder_method 改为 goto_folder 并重启工具。
Q: 保存的网页没有图片 / 保存格式?
A: 两种格式都支持:Edge 里「另存为」选「网页,全部」会生成 .html + _files 文件夹,
   选「网页,单一文件」会生成 .mhtml 单文件(含全部图片)。工具两种都能自动识别,无需改动。
Q: 保存后下载弹窗遮挡页面?
A: 点击页面任意位置即自动关闭;查下一个单子时第一次点击(姓名输入框)就会把它点掉,无需额外处理。
Q: 详情页没有保存/保存错了?
A: 确认 enable_detail=true、detail_mode 与页面实际行为一致;必要时重新标定。
Q: 换了窗口位置/换了显示器?
A: 标定后若窗口被意外移动,工具会自动补偿坐标继续跑(日志会提示位移量);
   换了显示器或窗口大小彻底改变时,重新「标定坐标」即可。
Q: 单个姓名失败后会自动重试吗?
A: 会。保存未确认时自动完整重查 1 次(可改 auto_retry);文件若已保存成功会自动识别跳过;
   文件被存到别处(如浏览器默认目录)时不重试,日志会提示文件位置。
Q: 查询结果汇总.xlsx 提示被占用无法写入?
A: 关闭正在打开该文件的 Excel/WPS,再点「导出 Excel」重新生成即可。

六、安全提示
------------
- 本工具不碰页面 JS、不改接口,仅模拟人操作,属于外部自动化;
- 仍请控制查询频率(默认已加随机延时),避免被平台风控;
- 名单与导出结果均保存在本机,请勿外泄。
